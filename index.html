使用 GitHub 账号提交申请。管理员批准后，你将获得私有发布仓库的只读权限，并可通过安装引导程序下载 CPU 或 NVIDIA GPU 版本。

管理员核对用途后添加 approved 标签，系统自动发送仓库邀请。

04

安装与更新

引导程序自动检测 NVIDIA GPU，下载安装并在后续版本发布时在线更新。

  • 授权仅绑定申请人的 GitHub 账号，不得转发安装包或登录凭据。
  • 软件包含 NeuroSim 及开源模型组件，使用时仍须遵守各自许可证。
  • 申请状态为 pending 时无需重复提交；批准后请先接受 GitHub 仓库邀请。
